# 🗺️ WeAct STM32F405RGT6 64-Pin Core Board — Hardware Pinout & Schematic Notes

Этот документ является единственным источником истины (Single Source of Truth) для маппинга пинов на плате WeAct F405. Все настройки в STM32CubeMX и код должны опираться на эти данные, подтвержденные принципиальными схемами.

## 1. Хранилище данных (MicroSD / TF Interface)
SD-карта распаяна напрямую на встроенный контроллер **SDIO (4-bit)**. Никакого SPI!
| Функция | Пин MCU | Примечание |
| :--- | :--- | :--- |
| SDIO_D0 | **PC8** | Data 0 |
| SDIO_D1 | **PC9** | Data 1 |
| SDIO_D2 | **PC10** | Data 2 |
| SDIO_D3 | **PC11** | Data 3 |
| SDIO_CMD | **PD2** | Command line (подтянут к VDD33 через 100k) |
| SDIO_CK | **PC12** | Clock |
| **SD_Card_Detect (CD)**| **PA8** | Механический переключатель слота карты (подтянут к 3.3V через 10k). Замыкается на GND, когда карта вставлена. |

## 2. Пользовательский интерфейс (Кнопки и Светодиоды)
Внимание: кнопки на этой плате имеют **Активный ВЫСОКИЙ уровень (Active HIGH)**!
| Функция | Пин MCU | Логика / Схема |
| :--- | :--- | :--- |
| **User Button (KEY)** | **PC13** | При нажатии замыкается на **VDD33 (3.3V)** через резистор 330 Ом. Имеет подтяжку. |
| **LED Blue** (Синий) | **PB2** | Анод к пину PB2 через резистор 5.1k, катод на GND. **Active HIGH** (1 = светится). |
| **LED Red** (Красный) | — | Это индикатор питания (PWR). Подключен напрямую к VDD33. Горит всегда, когда плата включена. |

## 3. Тактирование и RTC (Clocks)
На плате установлены два физических кварцевых резонатора.
| Функция | Пины MCU | Частота | Примечание |
| :--- | :--- | :--- | :--- |
| **HSE** (High-Speed) | **PH0** / **PH1** | 8 MHz | Основной тактовый генератор для PLL (нужен для 168 MHz). |
| **LSE** (Low-Speed) | **PC14** / **PC15** | 32.768 kHz | Используется исключительно для точного хода внутреннего RTC (Real-Time Clock). |

## 4. Питание (Power & VBAT)
| Функция | Пин MCU | Примечание |
| :--- | :--- | :--- |
| **VBAT** | **VBAT** | Питание RTC. На плате есть батарейный отсек/пин, защищенный диодом BAT54C. |
| **VDD33** | VDD / VDDA | Основное питание 3.3V (через LDO ME6231A33PG от USB VBUS или внешнего VCC). |

## 5. Отладка (SWD)
| Функция | Пин MCU | Примечание |
| :--- | :--- | :--- |
| SWDIO | **PA13** | Data |
| SWCLK | **PA14** | Clock |

## 6. Свободные шины SPI (для внешнего акселерометра LIS3DSH)
Поскольку LIS3DSH у нас будет внешним (плата в пути), мы можем использовать свободные пины SPI1. Согласно схеме, эти пины выведены на гребенки:
| Функция | Рекомендуемый Пин MCU | Примечание |
| :--- | :--- | :--- |
| SPI1_SCK | **PA5** | Выведен на гребенку P1 (пин 15) |
| SPI1_MISO | **PA6** | Выведен на гребенку P1 (пин 17) |
| SPI1_MOSI | **PA7** | Выведен на гребенку P1 (пин 18) |
| LIS3DSH_CS | **PA4** (или любой другой GPIO) | Выведен на гребенку P1 (пин 14). Управляется программно. |

## 7. USB Type-C (для будущего)
| Функция | Пин MCU | Примечание |
| :--- | :--- | :--- |
| USB_DP | **PA12** | Data Plus |
| USB_DN | **PA11** | Data Minus |

---
**⚠️ ВАЖНЫЕ ЗАМЕТКИ ДЛЯ КОДА И CUBEMX:**
1. Кнопка (PC13) активна ВЫСОКИМ уровнем (нажали -> на пине 1).
2. Детект SD-карты (PA8) активен НИЗКИМ уровнем (карта вставлена -> на пине 0, вытащили -> 1).
3. Светодиод (PB2) зажигается ВЫСОКИМ уровнем (написали 1 -> горит).
4. Для RTC обязательно выбирать источник тактирования **LSE** (внешний кварц 32.768 кГц на PC14/PC15), а не встроенный LSI.
5. ## ⚠️ HIL vs Production Pin Conflict (flagged by qwen3.8-27b)
- HIL test: PA5 = DAC_CH2 (sine wave out) -> ADC (PA0, PA1, PA2)
- Production (LIS3DSH): PA5 = SPI1_SCK
- Migration plan: when LIS3DSH arrives, DAC must move to PA4 (DAC_CH1) or be disabled entirely.
